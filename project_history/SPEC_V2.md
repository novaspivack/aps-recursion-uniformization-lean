## Clone Theory / Universal Algebra / Iteration Theory Attack Plan

### Target: the recursion–composition frontier in abstract IndexedAPS

The goal is no longer framed naively as I_rec ⇒ I_comp. The goal is now to resolve or sharply classify the frontier through the correct structural bottlenecks:

- I_rec ⇒ SmnTrackingRecursion ?
- I_rec ⇒ SmnSectionSurjectiveAt(x₀) for all x₀ ?

The program is now explicitly **algebraic** and **uniformization-theoretic**.

---

# 0. Core diagnosis

Phase III has established:

1. I_comp is exactly **uniform smn-tracking**.
2. I_rec gives only **pointwise fixed points**.
3. The gap is: section surjectivity, finite tracking, coherence, gluing, and ultimately interpolation / merging.
4. The strongest evidence suggests the problem is not about more diagonal tricks, but about whether the smn-generated operation system has enough algebraic structure to upgrade local behavior to global behavior.

So the new Phase III question is:

> Does the algebra generated by smn_spec and I_rec force an interpolation principle strong enough to yield uniform tracking?

---

# 1. Primary mathematical lenses

There are now **three** main lenses.

## Lens A — Clone theory / universal algebra

Treat the smn-generated families as term operations / clone fragments and ask whether local section behavior forces global realizability.

**Primary lens.**

## Lens B — Iteration / Conway / preiteration theory

Treat I_rec as a fixed-point axiom and ask whether the missing step is precisely the parameter identity or an equivalent law.

**Secondary conceptual lens.**

## Lens C — Model theory / compactness

If the implication is false, a countermodel may need model-theoretic construction rather than hand-built toy design.

**Negative / independence lens.**

# 2. Program objectives

The program succeeds if it proves any of the following.

## Outcome A — Positive theorem

A theorem of the form I_rec + X ⇒ I_comp or I_rec + X ⇒ SmnTrackingRecursion for a natural algebraic hypothesis (X).

## Outcome B — Algebraic exactness

A theorem of the form X ⇔ finite-to-global interpolation for smn-tracking and X + I_rec ⇔ I_comp (or similarly strong corrected exactness).

## Outcome C — Countermodel

A model of I_rec ∧ ¬I_comp or at least I_rec ∧ ¬SmnSectionSurjectiveAt(x₀) constructed conceptually, not by finite toy search.

## Outcome D — Independence-style result

A mathematically serious argument that the missing property is independent of the current APS axioms, or that one needs an additional interpolation/parameter axiom.

# 3. Workstreams

## Workstream A — Clone semantics of smn

**Goal:** Formalize the operation system generated by smn and determine whether it behaves like a clone / partial clone / Lawvere theory fragment.

**Central question:** What are the "term operations" in the APS generated by constants / representable functions, the pairing map, and the specialization law smn_spec?

**Deliverables:** Define candidate notions: SmnCloneReachable, SmnTermOperation, SmnCloneInterpolates, FiniteSmnInterpolable.

**Theorem targets:**
1. I_comp_as_clone_surjectivity — restate I_comp as surjectivity of the smn-clone onto representable unary maps
2. section_surjectivity_as_clone_projection — identify SmnSectionSurjectiveAt as surjectivity of a projection/specialization map in the clone
3. finite_tracking_as_local_clone_interpolation — characterize finite tracking as local interpolation in the clone

**Stop condition:** Clean algebraic dictionary between APS notions and clone-theoretic notions.

---

## Workstream B — Interpolation / Baker–Pixley route

**Goal:** Determine whether some local-to-global interpolation theorem can force global tracking from finite tracking.

**Central question:** Is there an analogue of Baker–Pixley (local agreement on finite sets implies global term representability) for the smn-generated operation system?

**Candidate hypotheses:** near-unanimity-like operations, majority-like operations, discriminator-like behavior, weak interpolation operators, amalgamation / extension axioms for sections, finite Helly/compactness properties for trackers.

**Theorem targets:**
1. finite_tracking_implies_global_under_X — FiniteTracking + X ⇒ SmnTrackingForRep
2. joint_section_surjectivity_implies_global_under_X — JointSectionSurjective + X ⇒ I_comp
3. no_baker_pixley_without_X — prove that some (X)-like ingredient is necessary for interpolation

**Stop condition:** Either find the correct interpolation principle (X), or prove why no naive local-to-global theorem can hold.

---

## Workstream C — Iteration / Conway / parameter identity translation

**Goal:** Make the iteration-theory analogy precise enough to become theorem-generating rather than rhetorical.

**Central question:** Is the APS gap exactly an instance of the gap between fixed-point existence and the parameter identity / functoriality / Bekič-like laws?

**Deliverables:** Define categorical/iteration-theoretic analogues of FullIndexedRecursion, SmnTrackingRec, SmnTrackingForRep, I_comp.

**Theorem targets:**
1. I_rec_as_preiteration_axiom
2. I_comp_as_parameter_identity
3. smn_spec_as_parameterization_schema
4. aps_parameter_identity_bridge — prove the strongest possible equivalence between APS uniform tracking and a parameter identity law
5. conway_counterexample_transfer or preiteration_gap_transfer — if a known preiteration model separates fixed-point from parameter identity, determine whether it can be interpreted as an APS-like structure

**Stop condition:** Either a positive derivation closes the gap, or a negative separation yields a conceptual counterexample template, or prove the analogy is structurally imperfect and isolate exactly where.

---

## Workstream D — Model theory / compactness / infinite countermodels

**Goal:** If the implication is false, construct a genuine infinite countermodel or prove strong partial independence evidence.

**Central question:** Can one build an infinite APS where recursion holds but section surjectivity or uniform tracking fails?

**Strategies:** Fraïssé-style amalgamation / non-amalgamation; compactness from finitely satisfiable fragments; ultraproduct / quotient-like constructions preserving I_rec but killing tracking; highly non-separable extensional classes; stratified models.

**Theorem targets:**
1. finite_consistency_schema — axiomatize finite approximations to I_rec ∧ ¬SectionSurjective
2. compactness_countermodel_candidate — if finitely satisfiable, derive an infinite candidate by compactness
3. no_compact_countermodel_up_to_schema — if compactness route fails, formalize why

**Stop condition:** Either a genuine infinite countermodel emerges, or the compactness route is blocked in a mathematically meaningful way.

---

## Workstream E — Synthesis / exactness closure

**Goal:** Turn the results of A–D into the final theorem.

**Possible outcomes:** I_rec + X ⇒ I_comp; I_rec ∧ ¬I_comp countermodel; exact characterization of the missing algebraic principle; rigorous non-derivability / independence-style statement.

**Final theorem targets:** recursion_uniformization_theorem, aps_interpolation_exactness, section_surjectivity_characterisation, recursion_comp_independence_schema.
